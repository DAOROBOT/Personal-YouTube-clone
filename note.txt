<html> element represents entire web page.

<body> = contains all elements that are visible
<head> = contains elements that are not visible.

<link> is a void element because this element doesn't need a closing tag.

display property:
	1. block element = takes up the entire line in their container, not necessarily the entire page
	2. inline-block element = only takes up as much space as needed.
	3. inline element = appear within a line of text

<div> = division
<div> is just a box, container
<div> by default is a block element.
Can put any other elements and the div itself inside a <div>

Grid

<div style="
	display: grid;
	grid-template-columns: 100px 100px 200px; /* first and second column have 100px width, third column has 200px */ 
">
	<div style="background-color: lightblue;">
		div1
	</div>

	<div style="background-color: lightpink;">
		div2
	</div>

	<div style="background-color: lightblue;">
		div3
	</div>

	<div style="background-color: lightpink;">
		div4
	</div>

</div>

When a div is inside a grid, the div is placed into a grid. So, instead of taking up the entire line in the webpage, the div takes up the entire column only.

When we have more divs than a number of columns, for example, 3 columns but for divs, the fourth div will start a new 

fr is free space.

A column is set to 1fr, will take up the entire free space left.

Flexbox is similar to CSS Grid, but it's more flexible.

Grid = rigid layout
Flexbox = flexible layout
